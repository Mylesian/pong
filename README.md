# PONG

Not actually pong! Tower defense game that I couldn't come up with a better name for so pong stuck.
Buy towers with money from the shop and place them by the track to hit enemies.
As waves increase, enemies get stronger and faster, requiring a better defense.
If an enemy makes it through, you lose health. If you lose all your health, you lose.
If you make it through every wave, you win!
